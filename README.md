# 💫 About Me:
I’m an AI/ML enthusiast and open-source contributor with a strong interest in Large Language Models (LLMs), machine learning systems, and end-to-end AI applications. I enjoy turning ideas into real-world projects by working across the full stack—from data preprocessing and model development to APIs and deployment.<br><br>I actively explore LLMs, prompt engineering, RAG (Retrieval-Augmented Generation), and model fine-tuning, and I’m passionate about understanding how things work under the hood rather than treating models as black boxes. Along the way, I build practical projects and share my learnings through code and experiments.<br><br>I also participate in Kaggle competitions and notebooks, where I focus on improving my data analysis, feature engineering, and modeling skills while learning from the global ML community.<br><br>I’m always excited to collaborate on open-source projects, contribute to meaningful repositories, and learn from others in the AI ecosystem.
